# CK-17 Engineering Investigation

## Purpose
To test the creator of this portfolio with a synthetic scenario about a plausible, real-world condition that might occur in an industrial style workplace. 

## System Description
CK-17 is a industrial liquid-cooling skid. It circulates an approximately 30% glycol/water mixture in a controlled loop. The major system components we established are a variable-speed centrifugal pump, a modulating bypass valve, a heat exchanger, an atmospheric reservoir, and a PLC-based control system.

The centrifugal pump provides coolant circulation, and its speed can vary.

The bypass valve can modulate, changing how flow is distributed through the hydraulic system.

The heat exchanger provides thermal management.

The atmospheric reservoir provides fluid inventory and means the system is not simply a completely sealed pressurized circuit.

The PLC controls/monitors the system and records the operating signals represented in the dataset.

## Constraints
1. Do not manufacture information that is not contained within the scenario.
2. Synthetic supplied dataset is ready only and must not be altered.
3. Measured observations, derived values, assumptions, and hypotheses must remain distinguishable from one another.
4. The hidden answer or intended failure mechanism is hidden from the investigator. Conclusion must be reached by the provided evidence.
5. A hidden answer key exists in the private source repository, but it is excluded from the investigation workflow and is not consulted during analysis.

## Investigation Method
1. Understand the issue.
2. Acquire dataset.
3. Analyze the data.
4. Record observations.
5. Request additional info, if necessary.
6. Create derived views or calculations to test theories.
7. Create conclusions from available evidence.
8. Document traceability to preserve process tools and history.
